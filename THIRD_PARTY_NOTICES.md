# Source provenance and third-party notices

The Python reference implementation and Kotlin/Android implementation are
DropNet project work developed with AI assistance and local human-directed
review. AI reviews are suggestions, not independent security certification.
The simulator is standard-library-only. Historical regression fixtures contain
synthetic events and output metrics generated by the project's simulator.

No code, credentials, runtime installation or proprietary model weights from
Free Claude Code, NVIDIA, Codex or the local coordination environment are
included in this source release. Those tools assisted development; running the
released Python demo does not require an AI service, account or API key.
